# AI Resume Screening System

An AI-powered resume screening system that helps recruiters analyze, match, and rank candidates based on job requirements. The system extracts information from resumes, compares candidate skills with job requirements, and helps recruiters identify suitable candidates.

## Features

* Recruiter registration and login
* Create and manage job roles
* Upload and process resumes
* Extract skills and relevant information
* Match resumes with job requirements
* Rank and shortlist candidates
* Store candidates and screening results in a database

## Tech Stack

* Python – Backend and AI/ML processing
* HTML & CSS – Frontend
* JavaScript – Frontend functionality
* SQLite – Database
* Pandas & Scikit-learn – Data processing and ML
* NLP techniques – Resume and skill analysis

